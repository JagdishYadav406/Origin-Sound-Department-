This is a simple envelope follower, not speech recognition or an automatic mix-quality decision. Master trim does not auto-normalize or limit; if the output would exceed full scale, rendering is blocked.

Timeline model: each track has source in/out trim points, a start offset, and linear fade-in/fade-out controls. Mono is centered; stereo is preserved as left/right.
